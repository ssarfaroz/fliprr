# fliprr — голосовое управление Claude Code и Claude

Говоришь из любой точки комнаты:

> **«Клод Код, запусти тесты и почини то, что упало»**

— Claude Code делает это в твоём проекте и голосом рассказывает, что сделал.

> **«Клод, как сварить борщ?»**

— обычный разговор с Claude, ответ звучит из колонок. Никаких кнопок: компьютер просто включён и слушает.

## Как это работает

1. Микрофон слушает постоянно. Детектор речи (Silero VAD) вырезает из звука отдельные фразы.
2. Каждая фраза распознаётся **локально** (faster-whisper) — звук никуда не отправляется.
3. Если среди первых слов есть **«Клод Код»** — задача уходит в Claude Code. Это настоящий Claude Code (через Claude Agent SDK): те же инструменты, настройки, `CLAUDE.md` и тот же вход в аккаунт, что и в терминале. Просто **«Клод»** — разговор с Claude (с поиском в интернете).
4. Ответ озвучивается по предложениям, пока Claude ещё пишет. Код и таблицы не зачитываются («код показан на экране») — весь текст виден в консоли.
5. Перед командами и правками файлов Claude Code **спрашивает разрешение голосом**: отвечаешь «да», «нет» или «да, и больше не спрашивай».
6. Несколько секунд после ответа можно продолжать **без имени**: «а теперь закоммить».

## Установка — один раз, одной командой

Нужно: **Python 3.10+**, микрофон и колонки, аккаунт Claude. Claude Code ставить отдельно не нужно — он идёт вместе с SDK; если ты уже пользуешься Claude Code на этом компьютере, вход в аккаунт уже есть.

**Windows** — в PowerShell:

```powershell
git clone https://github.com/ssarfaroz/fliprr; cd fliprr; powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

**macOS / Linux** (на Linux сначала `sudo apt install libportaudio2`):

```bash
git clone https://github.com/ssarfaroz/fliprr && cd fliprr && ./scripts/install.sh
```

Установщик всё сделает сам, задав пару вопросов:

1. поставит нужные пакеты;
2. спросит папку проекта, в которой будет работать Claude Code;
3. скачает модель распознавания речи (~500 МБ, только в первый раз);
4. проверит вход в Claude — если входа нет, предложит войти (откроется браузер);
5. проверит микрофон и колонки и скажет тестовую фразу;
6. включит автозапуск и запустит fliprr.

**После этого ничего запускать не нужно.** При каждом входе в систему fliprr стартует сам и слушает. На Windows это свёрнутое окно «fliprr» на панели задач: там видно, что он услышал и что ответил Claude; закроешь окно — fliprr выключится до следующего входа. Если он упадёт или микрофон ещё не подключён, он перезапустится сам.

Нет Python на Windows: `winget install -e --id Python.Python.3.12`, затем закрой и снова открой PowerShell.

## Управление

На Windows команды запускаются из папки fliprr как `.\fliprr.bat <команда>`, на macOS/Linux — `fliprr <команда>`:

| Команда | Что делает |
|---|---|
| `setup` | пройти настройку заново (сменить папку проекта и т. п.) |
| `autostart off` · `autostart on` | выключить / включить автозапуск |
| `test-mic` | проверить микрофон издалека: скажи «Клод Код, покажи статус гита» |
| `doctor` | проверить всё разом |
| `login` | войти в аккаунт Claude |
| *(без команды)* `--keyboard` | запустить вручную; с `--keyboard` можно ещё и печатать запросы |

Офлайн-голоса Piper (без интернета): `.venv/bin/pip install -e ".[piper]"` (Windows: `.venv\Scripts\pip install -e ".[piper]"`) и в настройках `[tts] engine = "piper"`.

## Что говорить

| Скажи | Что будет |
|---|---|
| «Клод Код, запусти тесты и почини, что упало» | задача для Claude Code в папке проекта |
| «Клод, сколько будет 17 процентов от 2300?» | ответ Claude голосом |
| «Слушай, Клод, …» / «Эй, Клод Код, …» | имя может быть не первым словом |
| «Клод Код!» … сигнал … «покажи статус гита» | можно позвать, дождаться сигнала и сказать задачу |
| *(сразу после ответа)* «а теперь закоммить» | продолжение без имени (8 секунд после ответа) |
| «да» · «нет» · «да, и больше не спрашивай» | ответ на вопрос о разрешении |
| «Клод, стоп» · «Клод, стоп, сделай по-другому» | прервать задачу (и сразу дать новую) |
| «Клод, замолчи» | замолчать, но не прерывать работу |
| «Клод, повтори» | повторить последний ответ |
| «Клод Код, новая сессия» · «продолжи прошлую сессию» | новая сессия / продолжить последнюю в этой папке |
| «Клод Код, проект блог» | переключиться на проект из настроек |
| «Клод, открой чат рецепты, как сварить борщ?» | именованные чаты: создать/открыть и сразу спросить |
| «Клод, новый чат» · «Клод, какие у меня чаты» | |
| «Клод Код, разрешай правки» · «спрашивай разрешение» | правки файлов без вопросов / снова спрашивать |
| «Клод, спи» … «Клод, проснись» | перестать реагировать на всё, кроме «проснись» |
| «Клод, статус» · «Клод, что ты умеешь» | |

Пока ассистент говорит, микрофон слышит и его самого, поэтому в это время он реагирует только на фразы, которые начинаются с «Клод…» (например «Клод, стоп» или новая задача), и на быстрые «да/нет» в ответ на вопрос. Продолжения без имени — после того как он договорил.

**Звуковые сигналы:** два тона вверх — слушаю; короткий — запрос принят; два тона вниз — ответ закончен, можно продолжать без имени; три коротких — жду «да» или «нет».

## Настройки

Файл создаёт установщик (или `fliprr setup`) (Windows: `%APPDATA%\fliprr\config.toml`, macOS: `~/Library/Application Support/fliprr/config.toml`, Linux: `~/.config/fliprr/config.toml`). Можно положить `fliprr.toml` в текущую папку или указать `--config`. В шаблоне всё прокомментировано; главное:

```toml
[claude_code]
cwd = "~/code/myapp"               # где работает Claude Code
permission_mode = "default"        # спрашивать голосом; "acceptEdits" — правки без вопросов
[claude_code.projects]             # «Клод Код, проект блог»
блог = "~/code/blog"

[stt]
model = "small"                    # см. таблицу ниже
language = "ru"

[tts]
voice = "ru-RU-SvetlanaNeural"     # или ru-RU-DmitryNeural
engine = "edge"                    # piper — полностью офлайн

[wake]
default_target = "chat"            # кого зовёт просто «Клод»: chat или code
followup_s = 8                     # 0 — выключить продолжение без имени
```

**Модель распознавания** (`[stt] model`):

| Модель | Качество | Скорость на обычном ноутбуке (CPU) |
|---|---|---|
| `base` | слабое для русского | очень быстро |
| `small` *(по умолчанию)* | хорошее | ~0.5–1 с на фразу |
| `medium` | очень хорошее | ~2–3 с на фразу |
| `large-v3-turbo` | лучшее | для видеокарты NVIDIA (`device = "cuda"`) |

Слабый компьютер? Распознавание через Groq (быстро, есть бесплатный тариф): `[stt] engine = "openai"`, переменная окружения `GROQ_API_KEY`. Учти: тогда **каждая** услышанная фраза отправляется в Groq.

## Чтобы слышал с другого конца комнаты

- Лучший вариант — **USB-спикерфон для конференций** со встроенным эхоподавлением (Jabra Speak, Anker PowerConf и т. п.): он слышит издалека и не слышит сам себя.
- Подними громкость микрофона в системе; если мало — `[audio] input_gain = 2.0`. Проверяй через `fliprr test-mic`.
- Если ассистент реагирует на собственный голос — сделай колонки тише или поставь `[audio] barge_in = false` (тогда во время ответа он не слушает).
- Если имя распознаётся по-своему — запусти `fliprr -v`, посмотри, что слышно, и добавь вариант в `[wake] extra_claude_words`.

## Как устроен автозапуск

Его включает установщик (или `autostart on`), выключает `autostart off`. Запустить второй экземпляр нельзя: если fliprr уже работает, новый запуск просто завершится.

- **Windows:** запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (без прав администратора) → окно «fliprr» стартует при входе и сворачивается.
- **macOS:** объект входа `~/Applications/fliprr.command`, открывается в Терминале. Терминалу нужен доступ к микрофону: Системные настройки → Конфиденциальность → Микрофон.
- **Linux:** пользовательская служба systemd (`~/.config/systemd/user/fliprr.service`), журнал — `journalctl --user -u fliprr -f`.

## Приватность

- Звук распознаётся на твоём компьютере (если не включён Groq/OpenAI).
- В Claude (Anthropic) уходит только текст запросов, обращённых к «Клод» / «Клод Код», — так же, как при работе в Claude Code.
- Голос `edge` отправляет текст ответов в сервис синтеза речи Microsoft. Полностью офлайн — `engine = "piper"`.
- Использование Claude считается по твоему тарифу Claude / API, как в обычном Claude Code.

## Проверка без микрофона

```bash
fliprr transcribe запись.wav                    # что распознано и кому адресовано
fliprr simulate фраза1.wav фраза2.wav           # весь ассистент на файлах, Claude не вызывается
fliprr simulate --agents claude --project . фраза1.wav да.wav   # с настоящим Claude Code
```

## Если что-то не так

- **«Claude Code не авторизован»** — `fliprr login`.
- **Не слышит** — `fliprr devices`, выбери микрофон в `[audio] input_device`; `fliprr test-mic`.
- **Высокая нагрузка на процессор** — `[stt] model = "base"` или Groq.
- **Linux: PortAudio not found** — `sudo apt install libportaudio2`.
- Всё проверить разом — `fliprr doctor`.

## Разработка

```bash
pip install -e ".[dev,piper]"
pytest
```

Устройство: `fliprr/audio` (микрофон, VAD, нарезка фраз, воспроизведение), `fliprr/stt` (распознавание), `fliprr/wake.py` (имя «Клод»), `fliprr/intents.py` (голосовые команды), `fliprr/agents` (Claude Code и чат через Claude Agent SDK, разрешения голосом), `fliprr/tts` (голоса и очередь речи), `fliprr/assistant.py` (логика разговора).

---

**English:** fliprr is an always-listening voice front end for Claude Code and Claude. Say “Claude Code, run the tests” or “Claude, what’s the weather?” from across the room; speech is recognized locally with faster-whisper, requests go to the real Claude Code via the Claude Agent SDK (permission prompts are answered by voice), and answers are read aloud. Set `language = "en"` and `[stt] language = "en"` for English.
